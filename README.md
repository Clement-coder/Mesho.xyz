# Mesho Data Sciences - Academic Research Support Platform

A modern Next.js web platform providing academic research support services for students, lecturers, and independent researchers.

## Features

- 🔐 **Authentication System**: Sign up/login with localStorage
- 📱 **Responsive Design**: Works on all devices
- 🎨 **Smooth Animations**: Framer Motion transitions and loading states
- 📊 **User Dashboard**: Track purchased materials and activity
- 📚 **Research Materials**: Browse 16 department-specific project topics
- 🎓 **SPSS Training**: Register for academic data analysis training
- 👨‍💼 **Hire Analysts**: Engage qualified academic data analysts
- 💬 **WhatsApp Integration**: Direct contact support
- 🎯 **Protected Routes**: Secure user areas

## Services

1. **Research Material Access** — Department-specific project topics with instant download after payment
2. **SPSS Data Analysis Training** — Structured training in academic data analysis
3. **Academic Data Analyst Hiring** — Professional support for data cleaning, analysis, and report writing

## Departments Covered

Accounting, Actuarial Science, Geography Education, Biology Education, Mathematics Education, Integrated Science Education, CRS Education, Marketing, Banking and Finance, Social Studies Education, History & International Relations, Political Science, English Education, Physics Education, Chemistry Education, Microbiology

## Tech Stack

- **Framework**: Next.js 16 with App Router
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **State Management**: React Context
- **Storage**: localStorage (demo)

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Project Structure

- `/app` - Next.js app router pages and components
- `/components` - Reusable UI components
- `/lib` - Utilities, context providers, and mock data
- `/public` - Static assets
